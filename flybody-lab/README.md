# Flybody Digital Specimen

A browser-based visual prototype using the official TuragaLab/flybody external OBJ meshes and XML hierarchy.

- Original model source: https://github.com/TuragaLab/flybody
- License: Apache-2.0 (upstream license applies to upstream assets)
- The page loads OBJ/XML assets directly from the upstream public repository. It does not copy or modify the user's existing blog files.
- This is a visual assembly, not MuJoCo policy playback. Wing motion and disassembly are visual effects. No complete internal brain, nerve or muscle model is included.

Open the GitHub Pages site after Pages is configured.
